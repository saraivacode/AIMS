# Federated Learning — Expected Outputs

Generated by `fl_main.py` via `--federated` or `--federated-only`.

## Per-experiment JSON files (12 FL + 3 centralized baselines)

| Pattern | Count | Description |
|---|---|---|
| `{Model}_{Dist}_{Strat}.json` | 12 | FL experiment result (e.g., `DNN_IID_FedAvg.json`) |
| `{Model}_centralized.json` | 3 | Centralized baseline (e.g., `GRU_centralized.json`) |

Each JSON contains: model_info, fl_config, metrics (final + per_round + convergence + history), performance, timestamps.

## Aggregated outputs

| File | Format | Description |
|---|---|---|
| `summary_table.csv` | CSV | Consolidated metrics: Accuracy, Precision, Recall, F1-Macro, @85%, @90%, Stability, Time |
| `summary_table.tex` | TEX | Same table in LaTeX format |
| `centralized_results.json` | JSON | All centralized baselines bundled in one JSON |
| `client_distribution_IID.png` | PNG | Stacked bar: class distribution across IID clients |
| `client_distribution_NonIID.png` | PNG | Stacked bar: class distribution across NonIID clients |
| `convergence_comparison.png` | PNG | 3 subplots (1/model): accuracy curves per strategy/distribution, 85%/90% reference lines |
| `strategy_comparison.png` | PNG | FedAvg vs FedProx convergence on NonIID data |
| `fl_vs_centralized.png` | PNG | Bar chart: best FL config vs centralized baseline per model |
